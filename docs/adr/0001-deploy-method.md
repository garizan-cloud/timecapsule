\# ADR-0001. Способ доставки кода



\- Статус: принято

\- Дата: 2026-10-04



\## Контекст



Нужно разворачивать приложение TimeCapsule на EC2 и регулярно

обновлять его код. Необходимо выбрать удобный способ доставки

изменений на сервер.



\## Решение



Использовать скрипт deploy.sh, который выполняет git pull,

composer install, инициализацию базы данных и reload PHP-FPM.

Скрипт запускается с компьютера одной командой по SSH.



\## Рассмотренные альтернативы



\### 1. scp



Файлы можно копировать непосредственно на сервер, но сложно

контролировать версии, легко забыть передать отдельные файлы,

а на сервере могут остаться устаревшие файлы. Зависимости и

таблицы базы данных при этом нужно обновлять отдельно.



\### 2. Ручной git pull



Сервер получает код из GitHub, и версия всегда известна по

коммиту. Но после git pull нужно вручную выполнить несколько

команд (composer install, init-db, reload php-fpm), и можно

пропустить любую из них.



\### 3. deploy.sh



Одна команда выполняет всю последовательность: git pull,

установку библиотек, создание таблиц, перезагрузку PHP-FPM.

Это уменьшает вероятность ошибки оператора, а сам скрипт

можно показать и проверить.



\## Последствия



Плюсы: простой повторяемый процесс, версия кода хранится в Git,

деплой легко повторить, скрипт останавливается при первой ошибке

(set -euo pipefail).



Минусы: запуск всё ещё выполняется вручную, автоматических тестов

и полноценного CI/CD пока нет. Для работы нужен доступ к серверу

по SSH.
